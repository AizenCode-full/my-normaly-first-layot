# Верстка корпоративного сайта IT-студии

Первая учебная верстка адаптивного сайта для передовой IT-студии. Проект выполнен на чистом HTML5 и CSS3 без использования сторонних фреймворков для демонстрации навыков базовой разметки и стилизации.

## О проекте

Передовая IT студия. Мы создаем легкие решения сложных задач и проблем. 

Этот сайт представляет собой интерфейс современной технологичной компании. Главная цель работы — применить на практике стандарты современной веб-разработки, создать чистую семантическую структуру и обеспечить корректное отображение на любых устройствах.

## Технологический стек

HTML5 — построение семантической структуры (использование тегов header, main, section, footer).
CSS3 — позиционирование элементов, работа с гибкими контейнерами (Flexbox/Grid), адаптивные медиазапросы.


## Реализованный функционал

Чистый код: валидная разметка, отсутствие лишних стилей и библиотек.
